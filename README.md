# Tugas-1-Algoritma-Pemrograman
# Study Case: Sistem Manajemen Toko “Cocoa Heaven”

oleh Azriel Yalsha Hanifah_124250058

  Toko cokelat Cocoa Heaven ingin membuat sistem sederhana berbasis C++ console
untuk membantu mengelola data karyawan dan barang di toko. Sistem ini digunakan oleh
admin dan karyawan dengan hak akses yang berbeda.
  Admin bertugas mengelola data karyawan, lalu disimpan ke dalam file Bernama
“karyawan.txt” sedangkan karyawan bertugas mengelola data barang seperti menambah
barang, melihat barang, mengedit barang, dan mengurutkan barang berdasarkan harga yang disimpan ke dalam file “barang.text”.
